# 🧬🦖 远古生命复原实验室 README

> 一个融合「史前生命遗迹」与「未来科研展厅」风格的单页交互网页。
> 以全息扫描、神经接口、化石档案与生命重建为主题，构建出一座“远古生物实验室”的沉浸式展示页面。

---

## ✨ 项目简介

这是一份以 HTML + CSS + JavaScript 构建的静态网页，页面核心氛围是：

- 远古生物与未来科技并置
- 全息扫描 + 量子复原 + 化石研究
- 史前巨兽轮播 + 生境模拟 + 时间裂隙体验
- 科研控制台 / 展馆导航 / 仿生数据面板

它不是普通的介绍页，而是一种“科幻博物馆展厅”的体验式页面，像是一座未来实验室里正在复原恐龙、猛犸象、沧龙与翼龙的神秘空间。

## 🧩 页面功能模块

### 1) 主展厅：远古生命复原实验室

- 以未来研发舱的观感为主
- 采用发光扫描环、粒子背景、全息扫描线、科幻仪表盘
- 展示“生命重建中的实验室状态”

图标：

```text
🧬 生命重建中
🧪 量子扫描中
🔬 断层识别中
🌌 全息投影中
```

### 2) 巨兽轮播：史前巨兽展馆

展示四类典型生物：

- 🦖 霸王龙
- 🦣 猛犸象
- 🦕 沧龙
- 🪽 翼龙

每个展品都有：

- 生物信息卡片
- Holographic line art
- 动态扫描强度调节
- 旋转视角与模型切换

### 3) 基因工坊：生物参数调校

在设计中，页面强调：

- 骨骼参数
- 神经接口
- 皮肤与颜色重建
- 生态适应度指标

像真实实验室一样，数据和生命体特征通过“可编辑的数值感知”被展现出来。

### 4) 生态模拟：深时环境重建

- 古环境能量链路
- 陆地 / 海洋 / 空中生境
- 气候与生态关系的可视化反馈

图标：

```text
🌍 陆地生态
🌊 海洋生境
🌤️ 大气环境
⚙️ 能量循环
```

### 5) 时间裂隙：跨时代穿梭

体现了“从寒武纪到白垩纪”的时间感，寓意是：

- 生命并非固定在某个时代
- 研究者正在通过时间裂隙重构历史生物

### 6) 控制甲板：实验室指挥中心

像真实的高科技实验台：

- 扫描进度
- 孵化状态
- 安全协议
- 运行日志

## 🧱 技术架构

该项目使用了最轻量的静态前端构建方式：

```text
HTML5      页面结构与语义元素
CSS3       动画、布局、背景、全息风格视觉
JavaScript 交互、粒子效果、轮播、状态更新、视角控制
Canvas     粒子场、实时动态扫描效果
```

### 关键文件

```text

├── assets/             # 图像资源和实验室视觉素材
├── docs/               # 设计说明与规划文档
├── tests/              # 页面结构验证脚本
├── README.md           # 项目说明文档
└── artifacts/          # 生成物与产出文件
```

## ▶️ 使用方式

### 方式 1：直接打开

在浏览器中直接打开：

```text
index.html
```

即可查看页面效果。

### 方式 2：本地静态服务器

如果你希望更稳定地查看动画效果，推荐运行：

```bash
python -m http.server 8000
```

然后访问：

```text

```
